**Xdemonlist**
The official Geometry Dash demonlist ranking the top 1 to 300 hardest custom levels in the game. 
This repository hosts the source code, level data, and record submission framework for the Xdemonlist platform.
🚀 **Features**
**Top 300 Ranking:**
Dynamically tracks and orders the 300 most difficult demons.
Submission System: 
Allows players to submit video proof of their completions.
**Leaderboards:**
Tracks player points based on level difficulty and placement.
**API Support:**
Accessible endpoints for developers to fetch current list statistics.
