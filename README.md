# XDemonlist

Fan-made Geometry Dash Demonlist website concept.

## Run it
Use VS Code + Live Server, or any simple local web server. Opening index.html directly with file:// may block the API request.

The Top 100 data, creators, verifiers, verification videos and thumbnails are pulled from Pointercrate's public API at runtime.

The site is designed around the July 2026 project concept. Because the API is live, the displayed ranking can change after July 2026.
